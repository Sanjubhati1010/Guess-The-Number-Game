# 🎯 Guess The Number Game

A simple and fun **Python Guess The Number Game** where the player competes against the computer.

## 📌 Features

* 🎲 Random number generation using Python `random`
* 🔢 Guess a number between **1 and 10**
* ✅ Input validation
* 🏆 Human and Computer score tracking
* 🚪 Press **Q** to quit the game
* 📊 Final score display
* 🔄 Play multiple rounds

## 🛠️ Technologies Used

* **Python**
* `random` module

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/Sanjubhati1010/Guess-The-Number-Game.git
```

2. Open the project folder:

```bash
cd Guess-The-Number-Game
```

3. Run the Python file:

```bash
python main.py
```

## 🎮 How to Play

1. Enter a number between **1 and 10**.
2. The computer randomly selects a number.
3. If your guess matches the computer's number, you get **1 point**.
4. Otherwise, the computer gets **1 point**.
5. Type **Q** anytime to exit.
6. The final score will be displayed.
